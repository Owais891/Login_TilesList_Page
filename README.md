# Orbit Tiles

A polished Flutter Material 3 demo featuring sign-in and sign-up screens,
remembered local demo sessions, a searchable responsive dashboard, and eight
interactive spaces.

## Demo sign-in

- Username: `demo` or `demo@orbit.app`
- Password: `password123`

Select **Remember me** to restore the demo user after the app is restarted.
Authentication is local demo logic in `lib/services/auth_service.dart`; replace
that service with a backend integration for production use.

## Run in Android Studio

1. Install the Flutter and Dart plugins and configure the Flutter SDK.
2. Open this project folder (`orbit_tiles`) in Android Studio.
3. Choose an Android emulator or connect an Android device with USB debugging.
4. Run `flutter pub get` in the terminal, then use **Run > Run 'main.dart'**.

From a terminal, the same app can be started with:

```shell
flutter pub get
flutter run
```

Run the checks with `flutter analyze` and `flutter test`.
